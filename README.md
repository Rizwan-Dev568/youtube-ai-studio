# 🎬 YouTube AI Studio

An AI-powered content production pipeline that automatically transforms a single topic into a complete YouTube production package.

From research to SEO, script writing, scene planning, character consistency, cinematic image prompts, AI video prompts, and voice prompts — everything is generated through a modular multi-agent architecture.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/YouTube_AI_Studio.git

cd YouTube_AI_Studio
```

---

## Create Virtual Environment

```bash
python -m venv .venv
```

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ⚙ Configuration

Create a `.env` file using `.env.example`.

Example:

```env
OPENROUTER_API_KEY=YOUR_KEY
```
